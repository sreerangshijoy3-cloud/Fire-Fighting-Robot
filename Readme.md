Arduino Firefighting Robot 

An autonomous firefighting robot built with Arduino that detects fire using flame sensors, navigates toward the flame, and extinguishes it using a water pump and nozzle system.

 Features

Autonomous Flame Detection: Uses three flame/IR sensors to locate fire (Left, Center, Right).

Obstacle Avoidance / Navigation: Steers toward the detected heat source while avoiding collisions using an ultrasonic sensor.

Automated Extinguisher: Activates a mini 5V DC submersible water pump when the flame is within reach.

Sweep Mechanism (Optional): Uses a servo motor to spray water across an arc for effective fire extinguishing.
